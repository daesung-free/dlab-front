## 화면별 상세

### 4.1 학생 관리

재원생 검색·상벌점·접수등록·반배정·사유신청

#### `F-4.1-1` 학원생 검색·조회

- **구분** 요구사항 검증됨 · **Phase** Phase 1 · MVP · FE 2순위
- **화면 경로** `/s/student-search`
- **기능 개요** 통합 검색(이름·학번·전화번호)·결과 정렬·검색조건 저장
- **데이터 항목** `students`
- **핵심 요구사항 · 로직**
  - GET /api/v1/students — QueryDSL 동적 검색 빌더 활용
  - 공통 검색 파라미터(year · branchId · keyword 등)
  - 엑셀 Export 마스킹 기본 ON (010-****-1234)
- **DSA 실사 근거** (코드 아님 · UX 참고용) DSA '학원생>메인메뉴'에서 12개 조건 검색필터, 394명 목록 확인. 결과 정렬·검색조건 저장은 화면에서 미확인 → 신규 요구사항으로 취급

#### `F-4.1-2` 상벌점 관리

- **구분** 요구사항 보완 · **Phase** Phase 1 · MVP · FE 2순위
- **화면 경로** `/s/student-penalty`
- **기능 개요** 항목 전년도 복사, 학생별 내역 조회·수정, 앱 Daily Report 실시간 연동, 상벌점 규칙 엔진
- **데이터 항목** `penalty_items`, `penalty_rules`
- **오픈이슈** #25(I-5) I-5(높음·운영팀)
- **핵심 요구사항 · 로직**
  - PenaltyRuleEngine — 트리거(지각/결석/루틴미완료)→점수 매핑 규칙 기반 자동 부여
  - YearlySnapshotService로 항목 전년도 복사
  - 중복 트리거 방지를 위한 멱등성 보장 필요
- **[0723 반영]** 학생 노출 명칭 완화 검토(관리점수 / 나의점수 등) — 운영팀 확정 대기

#### `F-4.1-3` 신규 접수 등록(합격생 등록)

- **구분** 요구사항 검증됨 · **Phase** Phase 1 · MVP · FE 2순위
- **화면 경로** `/s/student-enroll`
- **기능 개요** 합격생 등록, 학번 자동 부여(매년 초기화)
- **데이터 항목** `students`

### 4.3 출결 관리

키오스크 직접 연동 기반 출결 수신·승인

#### `F-4.3` 출결 관리

- **구분** 요구사항 보완 · **Phase** Phase 1 · MVP · FE 2순위
- **화면 경로** `/s/attendance`
- **기능 개요** 키오스크 실시간 수신(대성전산 API 경유 제거, 직접 연동), 일별 현황(담당 반 필터), 사유 실시간 수신·승인
- **데이터 항목** `attendance_logs`, `absence_requests`, `study_sessions`
- **오픈이슈** #2(D-2) D-2(최우선·대성전산 협의)
- **핵심 요구사항 · 로직**
  - POST /webhooks/kiosk/attendance — 서명검증(HMAC) → NFC/RFID 카드-학번 매핑 → 상태계산 → 알림톡 → PenaltyRuleEngine
  - 상태값 5종: ON_TIME / LATE / ABSENT / OUT / EXCUSED
  - 결석은 배치 스케줄러로 최종 확정
  - 키오스크 스펙(D-2) 미확정 시 목업 payload로 개발
- **[0723 반영]** 사유 지각신청 없이 미등원 시 학생·학부모에게 지각 알림 + 지각사유 회신 요청 자동 발송(무단지각 자동 감지)
- **DSA 실사 근거** (코드 아님 · UX 참고용) DSA 'D.Lab>출결 관리'에서 검색(학번/반/좌석/날짜)·출결목록(등원/하원/외출/공부시간)·학습시간 일괄계산 확인. 직접 Webhook 연동은 신규
